# edu-ppt-creator

Skill cho Claude: tạo và kiểm tra bài giảng PowerPoint (.pptx) môn Lịch sử và Địa lí THCS theo Chương trình GDPT 2018.

## Cấu trúc

```
edu-ppt-creator/
├── SKILL.md    # Nội dung skill (bắt buộc)
├── README.md
└── LICENSE
```

## Cài đặt

**Claude.ai:** Settings → Capabilities → Skills → tải lên tệp ZIP của thư mục `edu-ppt-creator` (SKILL.md nằm trong thư mục này).

**Claude Code:** chép thư mục `edu-ppt-creator` vào `~/.claude/skills/` (toàn cục) hoặc `.claude/skills/` (theo dự án).

## Lưu ý

Module 8 chỉ hướng dẫn AI kiểm tra và dùng công cụ cục bộ (Python, LibreOffice, Ollama, ComfyUI). Mô hình đám mây không chạy nhanh hơn nhờ CPU/GPU của máy.
